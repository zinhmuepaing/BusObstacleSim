# Assets and licences

Every asset in the project, where it came from, and its licence. CLAUDE.md rule 12.

## Third-party assets imported

None. No Asset Store packs, Sketchfab models or texture libraries have been imported.

## Generated in-project (owned by the project)

All of these are created by editor code in `Scripts/Editor` (moving to the package in M7) and can
be regenerated at any time from the BusSim menu.

| Asset | Path | Generated by |
|---|---|---|
| Road, footpath, ground textures (procedural noise and paving joints) | embedded in `Materials/Road_*.mat` | `ProceduralTextures`, `RoadMaterialFactory` |
| Road materials, procedural sky material | `Materials/Road_*.mat`, `Materials/Sky_Procedural.mat` | `RoadMaterialFactory`, `RoadSceneBuilder` |
| Road meshes, edge guard collider, zone markings | embedded in `Scenes/SampleScene.unity` | `RoadMeshBuilder`, `ZoneBuilder` |
| Bus physics material | `Materials/BusSlide.asset` | `TestRigBuilder` |
| Test bus prefab and materials | `Prefabs/TestRig/TestBus.prefab`, `Materials/Bus_*.mat` | `TestRigBuilder` |
| Traffic cone mesh | `Meshes/TrafficCone.asset` | `ProceduralMeshes` |
| 14 obstacle prefabs and their materials | `Prefabs/Obstacles/*.prefab`, `Materials/Obstacle_*.mat` | `ObstacleContentBuilder` |
| Obstacle definitions, difficulty profiles, road settings | `Data/**/*.asset` | `ObstacleContentBuilder`, `RoadSceneBuilder` |

Models are built from Unity primitives (cubes, spheres, capsules, cylinders) plus one procedural
cone mesh. Licence: same as the project.

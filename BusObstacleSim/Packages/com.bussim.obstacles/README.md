# Bus Obstacle Simulator (com.bussim.obstacles)

Random, realistic road obstacles for a Singapore bus driver training simulator. Every run is
different, every run can be replayed from its seed, and the driver always has room to pass.

## Install

Unity 6.6 or later. In Package Manager choose **+ > Install package from disk** and pick this
folder's `package.json` (or add `"com.bussim.obstacles": "file:<path to this folder>"` to
`Packages/manifest.json`). Splines and Input System are installed as dependencies.

## Quick start (about 2 minutes)

1. Open an empty scene.
2. Run **BusSim > Create Demo Scene**. It adds the `Obstacle` tag and `Obstacles` layer if
   missing, builds the road, sky, bus stop and school zones, all obstacle content, the test bus
   with a chase camera, and the obstacle spawner.
3. Press Play. Drive with W A S D or the arrow keys. The console logs the seed and per-type counts.

## How it works

- **Plan, then activate.** `SpawnPlanner` builds the whole run from a seeded `System.Random`
  before the bus moves. `ObstacleSpawner` activates pooled obstacles 150 m ahead of the bus and
  releases them 50 m behind it.
- **Always passable.** `ClearanceValidator` rejects any static obstacle that would leave less than
  the minimum clear corridor (3.2 m) across its length plus 15 m before and after, including when
  it sits next to obstacles already placed.
- **Dynamic obstacles** (pedestrians, cyclists, vehicles) start when the bus's time to arrival
  drops below their trigger and must leave the carriageway within `maxBlockSeconds`.
- **Road space.** `RoadSampler` converts between world space and (s, t): s metres along the
  spline, t lateral offset, positive to the right of travel. Left-hand traffic.

## Adding an obstacle type

1. Make a prefab: root with an `ObstacleBehaviour` subclass, a trigger `BoxCollider` matching the
   footprint, tag `Obstacle`, layer `Obstacles`, pivot at the ground centre, forward along the road.
2. Create an `ObstacleDefinition` asset (Create > BusSim > Obstacle Definition) and point it at the prefab.
3. Add it to a `DifficultyProfile`. No spawner code changes.

## Main components

| Component | Role |
|---|---|
| `RoadSampler`, `RoadSettings`, `RoadMeshBuilder`, `RoadZones` | Spline road, road space, meshes, zones |
| `ObstacleDefinition`, `DifficultyProfile` | Data: types, density, weights, categories |
| `SpawnPlanner`, `ClearanceValidator` | Pure C# planning and validation |
| `ObstacleSpawner`, `ObjectPool`, `RunLogger`, `DebugGizmos` | Runtime activation, pooling, logging, debug view |
| `StaticObstacle`, `PedestrianCrossing`, `PassengerRush`, `CyclistRide`, `MotorcycleFilter`, `CarCutIn` | Behaviours |
| `TestBusController`, `FollowCamera`, `TestBusAutopilot` | Optional test rig |

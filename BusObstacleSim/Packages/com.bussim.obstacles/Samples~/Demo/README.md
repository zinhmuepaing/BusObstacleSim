# Demo scene sample

The demo is generated, not shipped as a scene file, so it always matches the package code.

1. Create or open an empty scene.
2. Run **BusSim > Create Demo Scene**.
3. Press Play and drive with W A S D or the arrow keys.

Try the Easy, Normal and Hard profiles on the `ObstacleSpawner` object, or turn off
"Random Seed Each Run" and type a seed to replay a run exactly.
